Spelling Mastery GameThis is a browser-based spelling application designed to transform spelling practice into a self-paced, pain-free mastery loop. It features an integrated Piggy Bank Economy to motivate students through tangible, real-world rewards.Core MechanicsPain-Free Mastery Loop: Replaces traditional penalties with a 4-Heart Hint Lock and a Visual Decoy Review Loop to build true phonemic awareness and resilience.TV Time Piggy Bank: Tracks active playtime and converts it into rewards, monitored by a 30-second Idle Timeout Anti-Cheat system.  Multi-User Support: Allows multiple students to play on the same device with independent save states for bank balances and audit logs.  Global Leaderboard: Tracks and dynamically displays the first students to achieve 100% flawless mastery on each spelling list.Premium Custom Lists & AudioTo successfully bypass GitHub Pages' strict 100-file upload limit, this project uses a custom Python script to generate high-quality audio files.  Parents submit their custom weekly spelling words via a Google Form.The administrator copies the submitted words into the generate_audio.py script.The script automatically generates .mp3 files into specific user subfolders.The administrator updates the premiumSpellingData object in the main codebase and pushes the changes to GitHub.Google Form Setup for ParentsTo seamlessly collect custom spelling words from your premium subscribers, create a simple Google Form with the following fields:Parent Email Address: Short answer for account verification.Child's Name: Short answer (this must perfectly match their active user profile name in the game).Weekly Word List: Paragraph text (instruct parents to separate their 15-20 words by commas).Reward Customization (Optional): Short answer if they want you to manually adjust their game's reward labels or exchange rates.
